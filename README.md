# GIFmaker

複数の画像をつないで、GIFアニメーションを作るアプリです。
インストールや会員登録は不要です。画像はすべてお使いの端末の中で処理し、外部へ送信しません。

## Webで使う（パソコン・iPad・スマートフォン）

**https://girlkisser3075.github.io/GIFmaker/**

ブラウザで開くとすぐに使えます。ホーム画面に追加すると、アイコンからアプリのように起動できます。

- iPhone／iPad（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」または「アプリをインストール」

一度開いたあとは、インターネットに接続していなくても使えます。

## ダウンロードして使う（PC）

- Mac: [GIFmaker-mac.zip](downloads/GIFmaker-mac.zip)
- Windows ほか: [GIFmaker.zip](downloads/GIFmaker.zip)

展開した「GIF作成」フォルダの「GIF作成.html」をダブルクリックすると、ブラウザで開きます。
詳しい使い方は、フォルダ内の「使い方.txt」とアプリ内の「?」ボタンをご覧ください。
