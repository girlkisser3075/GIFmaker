The fonts are embedded in WOFF2 format, a lossless repackaging of the original OTF files.
Glyphs, metrics, naming and licensing metadata are unchanged; only the empty DSIG table is
omitted, as the WOFF2 format requires.
GifSans and GifSerif are CSS aliases used by this application.
